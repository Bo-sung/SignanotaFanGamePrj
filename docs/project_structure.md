# 프로젝트 구조 문서

## 개요
이 문서는 현재 프로젝트의 폴더 및 파일 구조에 대해 설명합니다.
이 프로젝트는 Unity 엔진을 기반으로 한 탑다운 슈팅 게임으로, 'Undead Survivor' 에셋을 활용하여 개발되었습니다.

## 주요 폴더 구조

*   **`Assets/`**: 게임의 핵심 에셋이 위치하는 메인 폴더입니다.
    *   **`Scenes/`**: 게임의 레벨 및 씬(`.unity`) 파일이 저장됩니다.
    *   **`Resources/Prefab/`**: 재사용 가능한 게임 오브젝트(예: 총알, 적 캐릭터)인 프리팹이 저장됩니다.
    *   **`Undead Survivor/`**: 'Undead Survivor' 에셋과 관련된 파일들이 포함되어 있습니다.
        *   **`Scripts/`**: 게임의 주요 로직을 담당하는 C# 스크립트 파일들이 있습니다.
            *   `Player.cs`: 플레이어의 동작 로직.
            *   `Enemy.cs`: 적 캐릭터의 동작 로직.
            *   `GameManager.cs`: 게임의 전반적인 흐름 관리.
            *   `Spawner.cs`: 적 생성 로직.
            *   `Weapon.cs`: 무기 관련 로직.
        *   **`Sprites/`**: 게임에 사용되는 이미지 파일 (캐릭터, 아이템 등).
        *   **`Animations/`**: 캐릭터 및 오브젝트의 애니메이션 파일.
        *   **`Audio/`**: 배경음악 및 효과음 파일.
*   **`docs/`**: 프로젝트 관련 문서가 저장되는 폴더입니다.
*   **`Packages/`**: Unity 패키지 매니저가 관리하는 외부 라이브러리 정보가 담겨있습니다.
*   **`ProjectSettings/`**: Unity 프로젝트의 각종 설정 파일들이 위치합니다.
